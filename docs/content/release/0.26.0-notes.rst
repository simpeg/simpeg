===========================
SimPEG 0.26.0 Release Notes
===========================

October DAYth, 2026

.. contents:: Highlights
    :depth: 3

Updates
=======

New features
------------

- TileMap –> use the discretize volume averaging by `@lheagy <https://github.com/lheagy>`__ in
  https://github.com/simpeg/simpeg/pull/1770

Extended support to Python 3.14
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

We extended support to Python 3.14 and Numpy 2.5. Starting from this release, we are running scheduled tests of SimPEG against the latest supported Python version and its dependencies.

Improvements to Natural Sources EM
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- NSEM receivers for 2D simulation by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1684
- Improved right-hand side for NSEM primary secondary by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1661
- Nsem recursive add zyx by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1766
- Stable padding for 1D MT solutions by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1769
- Add rotation invariant transfer functions by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1779

Improvements to simulations that use ``multiprocessing``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- Enhance robustness and error handling in multiprocessing simulations
  by `@jcapriot <https://github.com/jcapriot>`__ in https://github.com/simpeg/simpeg/pull/1776
- Make multiprocessing potential field kernel build using shared memory
  by `@jcapriot <https://github.com/jcapriot>`__ in https://github.com/simpeg/simpeg/pull/1816


Documentation
-------------

We moved the :ref:`Contributing Guide <contributing>` to its own separated section within the :ref:`User Guide <user_guide>`, and we included a new page explaining the process of :ref:`deprecating and removing code <deprecations>`.

The documentation also received some minor fixes in style and some mathematical expressions.


Bugfixes
--------

This release introduces the following bug fixes:

- Fix line feeds in natural_source/simulation.py to be LF instead by
  `@jcapriot <https://github.com/jcapriot>`__ in https://github.com/simpeg/simpeg/pull/1772
- Make ``simpeg.utils.download`` respect the ``verbose`` argument by
  `@manduinca <https://github.com/manduinca>`__ in https://github.com/simpeg/simpeg/pull/1777
- Fix Maxwell equation in FDEM module description by `@santisoler <https://github.com/santisoler>`__ in
  https://github.com/simpeg/simpeg/pull/1778
- Fix bug in ``getJ`` method of FDEM simulations by `@lheagy <https://github.com/lheagy>`__ in
  https://github.com/simpeg/simpeg/pull/1822


Breaking changes
----------------

This release drops support for Python 3.11 (see `#1802 <https://github.com/simpeg/simpeg/pull/1802>`__) since it reaches its end-of-life by the end of this month.

We removed some deprecated bits of code that were due for this minor release:

- Remove the ``warn`` argument in ``get_default_solver`` in https://github.com/simpeg/simpeg/pull/1797
- Removed deprecated directives submodules in https://github.com/simpeg/simpeg/pull/1798
- Remove deprecated properties of optimizers in https://github.com/simpeg/simpeg/pull/1799
- Remove deprecated properties from directives in https://github.com/simpeg/simpeg/pull/1800
