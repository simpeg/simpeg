===========================
SimPEG 0.26.0 Release Notes
===========================

October DAYth, 2026

.. contents:: Highlights
    :depth: 3

Updates
=======

New features
------------

- NSEM receivers for 2D simulation by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1684
- Improved right-hand side for NSEM primary secondary by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1661
- Nsem recursive add zyx by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1766
- Stable padding for 1D MT solutions by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1769
- Bump Python version to 3.14 in ``environment.yml`` by `@santisoler <https://github.com/santisoler>`__ in
  https://github.com/simpeg/simpeg/pull/1813
- Enhance robustness and error handling in multiprocessing simulations
  by `@jcapriot <https://github.com/jcapriot>`__ in https://github.com/simpeg/simpeg/pull/1776
- Make multiprocessing potential field kernel build using shared memory
  by `@jcapriot <https://github.com/jcapriot>`__ in https://github.com/simpeg/simpeg/pull/1816
- Add rotation invariant transfer functions by `@dccowan <https://github.com/dccowan>`__ in
  https://github.com/simpeg/simpeg/pull/1779
